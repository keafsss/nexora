# nexora

Short project description.

## Tech Stack

- React
- SCSS Modules

## Installation

```bash
git clone <repository_URL>
cd <project_folder_name>
npm install
```

## Environment Variables

If an `.env.example` file exists, copy it and fill in the values:

```bash
cp .env.example .env
```

## Running in Development Mode

```bash
npm start
```

The project will be available at `http://localhost:3000` (Create React App).

## Production Build

```bash
npm run build
```
